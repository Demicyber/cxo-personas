# 中国版 CXO Personas 研究笔记

## 一、中国企业高管Title体系 vs 西方CXO

### 核心Title对照表

| 中文Title | 西方对应 | 备注 |
|-----------|----------|------|
| 董事长 | Chairman | 国企里常兼党委书记，是真正的最高权力 |
| 总裁 | President | 集团级，比总经理高；华为的"轮值董事长"是独特模式 |
| 首席执行官 | CEO | 非法定职务，主要科技/互联网/境外上市公司使用 |
| 总经理 | GM/CEO(视语境) | 公司法规定的最高运营职务，所有公司必须设置 |
| 副总裁 | EVP/SVP | 比西方VP更高级，更接近EVP |
| 副总经理 | Deputy GM/VP | 国企和传统企业的标准高管title |
| 总监 | Director/Sr. Director | 如市场总监、技术总监 |
| 首席XX官 | CXO | 主要科技/互联网公司采用 |

### 关键区别
- **总经理**是法定角色，**CEO**不是 —— 法律上只认总经理
- **总裁 vs CEO vs 总经理**：总裁≈集团President，CEO是品牌化称呼，总经理是法定运营一把手
- 中国公司更多用"XX负责人"、"分管副总"这种功能性描述，而不是CXO

### 各CXO角色在中国的普及度

| 角色 | 普及度 | 说明 |
|------|--------|------|
| CEO | 高 | 科技、互联网、外企、境外上市 |
| CFO | 高 | 上市公司必须有"财务负责人" |
| CTO | 高 | 科技公司 |
| COO | 中高 | 互联网公司 |
| CMO | 中 | 消费品/互联网 |
| CIO | 中 | 大型企业，尤其制造业 |
| CHRO | 中 | 大型科技公司 |
| CDO | 低→中 | 政策推动（2021+要求国企设置） |
| CAIO | 极低 | 几乎不存在，AI归CTO或"AI负责人" |
| CRO | 极低 | 中国用"销售副总裁/商务副总裁" |
| CISO | 低→中 | 数据安全法推动中 |

## 二、按企业类型划分的组织架构

### 央企/国企
```
党委书记/董事长（常同一人）
├── 总经理/党委副书记
│   ├── 副总经理 × 3-6人
│   ├── 总会计师（法定，替代CFO）
│   ├── 总工程师（工业国企特有）
│   ├── 总经济师（部分国企）
│   └── 总法律顾问
├── 纪委书记
└── 工会主席
```
- 不用"首席XX官"，标配是副总经理体系
- 总会计师（替代CFO）是国务院法规要求
- 总工程师是工业国企特有的技术最高权威
- 领导任命来自中组部或国资委

### 民企（大型科技/互联网）
```
董事长/CEO（常为创始人）
├── 总裁/COO
├── CFO
├── CTO
├── 事业群总裁
├── SVP/VP
└── 总监
```
- 大量采用西方CXO title
- 扁平化、矩阵管理
- 特殊结构：阿里"合伙人制"、华为"轮值制"

### 外企在华
```
大中华区总裁
├── 各职能VP（销售/市场/HR/财务）
├── 各业务线总经理
└── 总监层
```
- 双语title标配
- 双线汇报（本地+亚太/全球）
- 重大决策需全球总部审批
- "法定代表人"是中国特有的法律要求

### 专精特新（中小隐形冠军）
```
董事长/总经理（同一人=创始人）
├── 副总经理 × 1-3
├── 技术总监/研发副总
├── 财务经理
└── 生产副总/厂长
```
- 高度创始人中心化
- 几乎不用CXO title
- 技术带头人虽无C-title但影响力巨大
- 任何¥10-50万+的采购创始人亲自看

## 三、党委在国企决策中的角色

### "三重一大"制度
党委会必须前置审议：
1. 重大决策
2. 重要人事任免
3. 重大项目安排
4. 大额资金运用

### 决策流程
```
党委会（前置研究讨论）→ 董事会（正式决议）→ 总经理办公会（执行部署）→ 执行
```

### 对B2B销售的实际影响
- 重大合同（通常¥500万-5000万+）需过党委会
- 战略合作/并购：必须党委批准
- 中层以上人事：党委最终决定
- IT/数字化大项目：需党委签字

## 四、决策权与采购权力地图

### 国企
| 决策类型 | 权力层级 | 关键决策人 |
|----------|----------|-----------|
| 战略供应商（>5000万）| 党委+董事会 | 董事长/党委书记 |
| 重大IT项目（1000万-5000万）| 总经理办公会+党委前置 | 总经理+分管副总 |
| 部门采购（<500万）| 分管副总审批 | 副总经理+部门负责人 |
| 日常采购（<50万）| 部门负责人 | 处长/部长 |

### 民企（大型）
- 战略合作：CEO/总裁+董事会，**创始人有一票否决权**
- 重大采购（>1000万）：CEO+CFO联合审批
- 部门预算（<500万）：VP/SVP级
- 关键洞察：**创始人的权力远超其title**

### 外企在华
- 中国战略：全球总部+中国区总裁提案
- 本地供应商（>$100万）：中国区总裁+亚太CFO
- 部门支出（<$50万）：本地VP/总监
- 关键洞察：**双线汇报，重大采购需全球采购审批**

### 专精特新
- **所有重要采购=创始人决定**
- 技术采购：创始人+技术总监共同判断
- 极度中心化

## 五、中国CXO的独特优先级

### 1. 政策驱动议程（vs 西方市场驱动）

| 政策主题 | 影响的CXO | 实际意义 |
|----------|-----------|----------|
| 新质生产力 | 全体 | 所有投资必须能对齐此叙事才能获得补贴和政治支持 |
| 数字中国 | CDO/CIO | 数据资产入表（2024.1生效）、数据作为生产要素 |
| 十四五收官（2025）| CIO/CTO | 政府关联企业面临KPI截止日，冲刺完成数字化指标 |
| AI+制造 | COO/CTO | 智能工厂认证、预测性维护、机器视觉 |
| 东数西算 | CTO/CIO | 数据中心选址须对齐国家算力枢纽布局 |
| 双碳目标 | CFO/CSO | 碳核算强制要求，ESG是合规不是自愿 |

**核心差异：政策驱动占中国CXO议程的30-50%（西方<10%）**

### 2. 国产替代/信创

| 角色 | 优先级 | 原因 |
|------|--------|------|
| CIO/CTO | ★★★★★ | 直接负责技术栈迁移 |
| CISO | ★★★★★ | 安全认证要求国产产品 |
| CEO(国企) | ★★★★☆ | 政治问责 |
| CFO | ★★★☆☆ | 短期成本2-3倍 |
| COO | ★★★☆☆ | 迁移期运营中断风险 |

信创栈：OS(麒麟/统信) → DB(达梦/OceanBase/TiDB) → 中间件(东方通) → 办公(WPS) → ERP(用友/金蝶)

2024-2025：金融核心系统进入信创"深水区"

### 3. 数据合规三法（数据安全法+个保法+网安法）
- CDO/DPO成为强制角色
- 跨境数据流动受限 → 架构必须数据本地化
- 等保2.0比西方框架更具体/强制
- CEO有"第一责任人"法律概念 → 个人刑事责任可能

### 4. 出海战略
- 双栈架构：国内（阿里云/华为云）vs 海外（AWS/GCP）
- 双重合规：中国法+目的地法
- 热门出海赛道：新能源车、游戏、电商、SaaS、工业设备
- CMO：抖音(国内) vs TikTok(海外) 完全不同打法

### 5. 中国特色科技生态
- **企业微信/钉钉/飞书**不只是IM，是企业操作系统（HR、财务、采购、CRM全嵌入）
- 选平台=选生态，切换成本极高
- **大模型**：算法备案制、私有部署偏好强（数据安全顾虑）、百模大战→整合期
- **低代码**：深度嵌入平台生态（钉钉宜搭、飞书多维表格），不像西方独立工具

### 6. 行业特殊性

| 行业 | 中国独特点 |
|------|-----------|
| 制造业 | 工业互联网800+平台、"灯塔工厂"政府认证驱动、5G+工互 |
| 金融 | 监管科技强制、普惠金融政治任务、核心系统信创 |
| 零售 | 社区团购、直播电商、私域流量（企微）、内容供应链 |
| 医疗 | 医保控费(DRG/DIP)、分级诊疗、互联网医院牌照 |

## 六、预算周期与采购模式

| 维度 | 中国企业 | 西方企业 |
|------|----------|----------|
| 预算周期 | 日历年(1-12月)，11-12月批次年预算 | 财年不固定，滚动预测 |
| Q4冲刺 | 年底突击花钱(花完预算保次年)，40-50%在Q4 | 相对均匀 |
| 政策联动 | 两会(3月)定调 → Q2调整预算 | 市场驱动 |
| 决策过程 | 共识+自上而下混合，"请示汇报"文化 | 更授权个人决策 |
| 招投标 | 国企超阈值必须公开招标 | RFP但更灵活 |
| 付款 | 60-180天，年底拖欠常见 | 30-60天 |
| 供应商关系 | 关系(Guanxi)仍重要，生态忠诚(全华为/全阿里) | Best-of-breed更常见 |
| POC | 大量免费POC期望 | 付费试用更被接受 |
| 合同结构 | 分阶段付款，尾款10-30%压验收 | 里程碑或订阅 |

## 七、信息获取渠道（替代年报/财报电话会）

### 推荐调研流程
1. **企查查/天眼查** — 建立事实基线（股权、经营范围变更、专利、关键人员）
2. **商业媒体**（36氪、虎嗅、钛媒体）— 找访谈、报道、融资
3. **微信公众号**（搜狗微信搜索）— 找高管署名文章和公司信息
4. **招标/中标公告** — 了解实际采购行为（最有价值的"revealed preference"）
5. **政策文件** — 理解监管压力和方向
6. **行业峰会演讲** — 找公开发言和Panel讨论
7. **脉脉/Boss直聘** — 了解招聘方向和内部动态
8. **行业报告** — 上下文化（信通院免费白皮书质量很高）

### 各来源对比

| 来源 | 时效性 | 深度 | 覆盖非上市 | 成本 | 可靠性 |
|------|--------|------|-----------|------|--------|
| 商业媒体 | 高 | 中 | 高 | 低-中 | 中 |
| 政府政策 | 低 | 高 | 中 | 免费 | 高 |
| 行业报告 | 中 | 高 | 中 | 高 | 高 |
| 企查查/天眼查 | 高 | 中 | 极高 | 低-中 | 高(事实类) |
| 行业峰会 | 周期性 | 高 | 中 | 中-高 | 中 |
| 微信公众号 | 极高 | 不定 | 高 | 免费 | 不定 |
| 招标/中标 | 高 | 极高 | 低-中 | 免费-低 | 极高 |
| 脉脉/招聘 | 高 | 低 | 高 | 低 | 低-中 |

## 八、中国版 vs 全球版的核心设计差异

| 维度 | 全球版 | 中国版需要 |
|------|--------|-----------|
| 企业分类 | 默认上市公司 | 央企/国企、民企(大型vs专精特新)、外企在华 |
| Persona触发 | Title → Persona | Title+企业类型 → Persona（同一title不同企业类型差异巨大）|
| 决策链 | Org chart线性 | 党委前置+双线汇报+隐性权力 |
| 优先级来源 | 财报/投资者沟通 | 政策文件+招标+公众号+峰会演讲 |
| 合规压力 | GDPR/SOX | 三法+信创+等保2.0 |
| 关系层 | 不包含 | 必须包含Guanxi建立节奏/中间人/标杆参访 |
| 生态绑定 | 无 | 企微/钉钉/飞书选择影响整体策略 |
| 预算周期 | 随公司财年 | 强日历年+政策周期(两会/十四五) |
| 语言 | 英文为主 | 中文为主，含英文专业术语 |
